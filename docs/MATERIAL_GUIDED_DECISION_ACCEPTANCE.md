# 对话式资料办理验收记录

日期：2026-09-07。范围：真实期间工作台的资料任务契约；资源版本 `guided-decision-2`。

## 交付结果

- 资料核实、红字／零金额发票、票据业务与科目、银行归属、暂缓、补充和重新识别复用一个逐步办理骨架。每步回答后展示摘要，只有明确提交才调用原业务动作。
- 步骤和问句由服务端选项描述提供，业务专用字段继续复用原插槽；没有改成通用任意改值接口。
- Agent 建议为用户主动请求，绑定当前任务与证据版本。只能建议已有可用选项；不确定、失败及未知情况保留人工处理路径，不预填业务事实，不执行业务命令。
- 建议记录与原业务模型覆盖分开。只有取得 Gateway 结果后才标识真实／模拟；未取得结果显示调用方式未知。
- 不自动重试新的模型请求；同请求号幂等，过期请求失败，迟到响应不能覆盖过期状态或抢走当前页面。
