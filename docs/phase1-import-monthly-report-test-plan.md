# FinWise 企业导入与月度财务报告测试计划

更新日期：2026-05-16

## 测试目标

验证 Phase 1 主流程中的两个新增能力：

1. 从代账测试资料目录批量导入企业基础信息和银行流水。
2. 按企业和月份基于已导入数据生成月度财务报告。

## 测试数据

SMB 源目录：

```text
/Volumes/共享文件夹/财务项目/银行流水
```

当前样本结构：

- 11 个企业目录。
- 14 个 Excel 银行流水文件。
- 文件前几行包含企业名称、纳税人识别号、经营范围。
- 部分文件包含 2-4 月单月流水，部分文件包含多月流水。

## 功能测试用例

| 编号 | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| F-01 | 批量导入 SMB 测试数据 | 企业名册页点击“导入测试数据” | 新增/更新企业，导入可解析流水，无后端 500 |
| F-02 | 重复导入 | 再次点击“导入测试数据” | 已导入文件跳过或更新，不重复创建企业 |
| F-03 | 企业列表刷新 | 导入后进入企业名册 | 显示导入企业，行业、省市、来源有默认值 |
| F-04 | 生成有流水月报 | 选择有 2026-04 流水的企业和月份 | 显示现金流入、现金流出、净现金流、流水笔数 |
| F-05 | 生成空数据月报 | 选择无该月流水的企业和月份 | 报告生成成功，风险提示显示数据不足 |
| F-06 | CSV 导出 | 月报生成后点击“导出 CSV” | 浏览器下载包含关键指标的 CSV |
| F-07 | 发票和流水共同聚合 | 先导入发票，再生成同月报告 | 报告包含发票张数、销项/进项金额和预计税费 |

## 边界测试用例

| 编号 | 场景 | 输入 | 预期 |
| --- | --- | --- | --- |
| B-01 | 目录不存在 | 非法 `directory_path` | 返回 400，提示目录不存在 |
| B-02 | 企业税号缺失 | Excel 未提供纳税人识别号 | 使用 `TEMP-*` 临时税号，不中断导入 |
| B-03 | 无交易表头 | Excel 只有说明页 | 文件记录到 errors，不影响其他文件 |
| B-04 | 多月文件 | 文件名为 `2-4月流水` | 交易按实际交易日期进入对应月份 |
| B-05 | 重复税号 | 同税号多文件 | 复用同一企业，不重复创建 |
| B-06 | 金额为空或 0 | 借贷金额都为空 | 跳过该行 |

## 接口验收

| 接口 | 用途 | 验收点 |
| --- | --- | --- |
| `POST /api/import/enterprises/from_directory` | 从挂载目录批量导入 | 返回文件数、企业数、流水笔数和错误列表 |
| `GET /api/enterprises` | 企业列表 | 导入后可分页查询 |
| `POST /api/reports/monthly/generate` | 生成月报 | 返回 `MONTHLY_FINANCIAL` 报告数据 |
| `GET /api/reports/monthly/{enterprise_id}` | 查询月报历史 | 可按年月筛选 |

## 剩余风险

- 当前样本只包含银行流水，发票维度需要额外导入发票 Excel 后才能验证税费计算的完整准确性。
- 部分银行文件的表头格式差异较大，已做容错，但仍需用更多银行格式扩充映射。
- 目录导入是 Phase 1 内部测试能力，不应直接暴露到公网生产环境。
