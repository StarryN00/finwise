## 固定采购场景

正常场景包含合同、进项发票、付款和入库四份资料：形成一个 BusinessEvent 与 ProcessingGroup，生成 5 项确定性检查，全部通过后可依次确认分组、确认规则、生成/复核凭证、建立交付包、导出并接收外部回执。

负向场景包含：

- 缺入库：保留业务组，证据缺口为 `STOCK_IN`，确认和交付被阻断。
- 付款与发票金额不一致：`PAYMENT_INVOICE` 与 `BALANCE` 阻断目标业务组，不影响其他 Scope 内安全组。
- 跨 Scope：不返回对象摘要，读写均拒绝并记录审计原因。
- 模型不可用或输出非法：Run 进入暂停，不能用假 JSON 或置信度继续。
- 已锁账期间：普通资料写入被拒绝。
