# 企业科技画像批量扫描 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 FinWise 增加企业科技画像批量扫描任务能力，支持按企业范围创建任务、跟踪单家企业状态、提交采集结果、前端查看任务与批量发起扫描。

**Architecture:** 后端以 `TechnologyScanJob` 表记录批量任务，以新增 `TechnologyScanJobItem` 表记录单家企业任务状态；采集器通过 API 标记运行、完成、失败和暂停。前端在企业名册提供选择企业与创建任务入口，并用抽屉展示任务进度。实际企查查/天眼查浏览器采集保持在本地脚本或 Codex skill 层，不嵌入 FastAPI 后端。

**Tech Stack:** FastAPI、SQLAlchemy、SQLite/PostgreSQL 兼容模型、Vue 3、Element Plus、Vitest、Pytest。
