# 企业科技资质画像 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 FinWise 增加企业科技资质画像能力，支持天眼查/企查查采集结果入库、企业名册和详情展示、人工确认，并为后续贷款评分预留结构化标签。

**Architecture:** 科技画像是企业主数据增强层，不进入月度工作包。后端新增 `TechnologyProfile / TechnologyTag / TechnologyScanJob` 模型、服务和 API；前端在企业名册和企业详情展示画像状态；采集端先提供本地脚本和结构化导入接口，后续再沉淀为 Codex skill。外部平台账号只通过本地登录态或本地 `.env` 使用，不写入数据库、不提交、不回显。

**Tech Stack:** Python FastAPI + SQLAlchemy + Pydantic；Vue 3 + Pinia + Element Plus；pytest / vitest；本地浏览器登录态用于后续天眼查/企查查采集。
