# 新用户开账引导与菜单整理设计说明

## 背景

生产环境可能是空库。用户首次进入系统时，如果只看到空表和多个菜单，会不知道下一步应该先创建企业、导入期初数据，还是创建月度工作包。这个问题不能靠提示文案解决，需要把首页、主按钮、菜单层级和工作路径一起调整。

## 产品原则

1. 首页必须明确告诉用户当前处于哪个阶段，以及下一步应该点击哪里。
2. 开账路径必须从系统操作顺序出发，而不是从功能模块堆叠出发。
3. 日常菜单需要服务高频工作，低频或过渡功能减少主导航曝光。
4. 顶部“创建本月工作包”在没有企业档案时必须引导去创建企业，不能打开空选择框。

## 首次开账状态

### 状态 1：空企业

- 识别条件：企业列表为空。
- 首页主动作：创建企业档案。
- 说明重点：先录入营业执照编号、行业、省市和基础信息。
- 禁止行为：直接创建月度工作包。

### 状态 2：已有企业但未创建工作包

- 识别条件：企业列表非空，月度工作包为空。
- 首页主动作：导入期初/历史账套。
- 辅助动作：创建月度工作包。
- 说明重点：先把期初资产负债表、利润表、历史凭证或余额导入，后续月度凭证和报表才有基准。

### 状态 3：已有月度工作包且存在待确认事项

- 识别条件：当前工作包存在待确认数。
- 首页主动作：进入凭证生成。
- 辅助动作：查看资金/发票台账。
- 说明重点：完成 AI 预处理后，由会计确认凭证和异常事项。

### 状态 4：当月凭证基本完成

- 识别条件：当前工作包待确认数为 0 或已进入可输出阶段。
- 首页主动作：进入输出中心。
- 辅助动作：查看账簿。
- 说明重点：检查账簿、生成申报辅助表、导出报表和健康诊断报告。

## 首页结构

首页新增“开账准备”工作台区块，放在指标卡片上方：

1. 当前状态标题。
2. 当前状态说明。
3. 主按钮和辅助按钮。
4. 六步时间线：
   - 第 1 步：建立企业档案
   - 第 2 步：导入期初/历史账套
   - 第 3 步：创建月度工作包
   - 第 4 步：导入当月资料
   - 第 5 步：AI预处理与凭证确认
   - 第 6 步：输出申报与报告

## 菜单整理

调整为以下分组：

- 核心工作：工作台
- 客户资料：企业名册、历史账套导入
- 月度作业：月度工作包、资金流水、发票台账、凭证生成
- 账务输出：凭证管理、账簿、输出中心
- 系统设置：科目设置、规则设置

“账目明细”保留路由与代码，但从左侧主导航隐藏。原因是它更像旧版本汇总视图，当前操作路径已经拆分为资金流水、发票台账和凭证生成，继续放在主菜单会干扰用户判断。

## 验收标准

1. 空库首页能直接看到“先创建第一家企业”入口。
2. 首页显示完整六步路径，且每一步能跳到对应页面。
3. 左侧菜单不再展示“账目明细”，但 `/account-details` 路由仍可访问。
4. 没有企业时点击顶部“创建本月工作包”，提示先创建企业并跳转 `/enterprises/init`。
5. 前端测试覆盖首页引导内容、菜单分组、隐藏旧入口和顶部按钮保护逻辑。
