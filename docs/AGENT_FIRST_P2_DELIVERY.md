## 已交付

- P0：全量银行笔数、收支总额及余额关系检查；发票汇总对账；工资映射按原件确定性回放。汇总行不作为交易，重解析保留版本并失效相关依赖。
- P1：版本化 ParsePlan、Gateway 结构识别、通用本地执行器。模型只返回表、行、列与字段定位；金额、日期和身份原值由程序从原件读取。
- P2：原件样本优先展示，允许选择表头、字段列及参考行；先本地预览，再查看影响并明确应用。同企业、同账套已确认格式可受控复用，每份原件重新检查。
- 原件哈希、Scope、权限、期间开放、版本冲突和幂等继续校验。人工确认、期初、业务证据和制证门禁没有放宽。
- 隐藏内容、未支持金额单位／币种、无缓存公式、越界定位和不完整数据范围不能靠模型建议直接放行。

首批通用结构解析覆盖 Excel 收入／支出分列银行流水、进项发票、销项发票。工资、单金额银行流水和已验证 PDF 继续走原有专用能力。未知布局、扫描件、非人民币元换算及 P3 不在此次完成范围。
