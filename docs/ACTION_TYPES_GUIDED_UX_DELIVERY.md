## 已完成范围

- 增加 `ObjectType.ACTION_TYPE`、`ontology-v1.3` 和服务端只读 ActionType 目录，声明适用谓词、证据、输入、效果、权限、撤销入口和兜底属性。
- 以标准化上下文和声明式规则替换 `classify_task` 业务 if-chain，并用 16 个特征化用例锁定原有专用路由和 SYSTEM 门禁。
- 接入 `record_judgement`、`suspend`、`request_supplement`、`mark_out_of_scope`、`escalate`，统一支持权限、版本、幂等、撤销、失效和审计。
- 所有兜底动作均不授予账务可用，不修改原件、事实金额、正式凭证或期间状态；`mark_out_of_scope` 在正式下游存在时失败关闭。
- 发布 `decision-v2`，补齐 `stage`、`why_now`、完整动作和结构化效果；旧 `decision-v1` 仅只读兼容。
- 所有成功命令和幂等重放都返回实时 `next`；工作台增加可下钻 `action_metrics`。
- 工作台首屏保留问题类型、原始值/提取值和明确下一步；次要统计、阶段说明、处理记录和口径默认收起；对话框开启时背景主动作隐藏且不可操作。
- 预留 `ACTION_TYPE_CANDIDATE_REQUESTED` 审计接口，未实现阶段 2 的对话层或自动审批。
