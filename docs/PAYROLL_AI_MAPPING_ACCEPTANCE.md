# 工资表 AI 格式适配验收

## 交付范围

真实期间工作台增加 XLS/XLSX 工资格式识别：AI 提议字段对应，本地原件取数，用户确认格式后才产生新版本事实。连续表、多行/合并表头、重复工资条采用明确结构边界；不承诺任意未知格式自动成功。

不改独立 Demo、static/index.html、另一套 Vue 系统、原始文件、基线门禁或交付规则。本轮不扩展其他资料类型的 AI 适配、OCR 或生产部署。

## 产品路径

全部资料 → 工资表「请核对字段对应」→ 查看每列原始样例及期间 → 必要时调整列并更新预览 → 勾选已核对 → 确认字段对应并提取 → 查看本期成果及剩余问题。

格式确认不等于逐条人工核实；AI 不更正工资、不推算缺失金额、不生成凭证。识别失败保留原因，只有明确重试才发起新任务。已应用的同一原件重新打开不创建新版本。同企业跨月复用仅复用已确认结构，每期重新取数。

## 独立复核

规格与质量由两个只读复核者分别完成。已修复其复现的漏行、后段应发/实发换列、币种误读、纵向合并重叠、旧模板误复用、连续表跨期串值、无缓存公式丢行、字段修正后预览过期、失败隐式重试、重复应用版本增长及轮询错目标问题，并新增对应回归。限定本轮范围的复核问题全部关闭；不等同于任意格式或生产验收。
