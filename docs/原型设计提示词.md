# 智税管家 原型设计提示词（用于 Stitch）

## 提示词

请帮我设计一个名为"智税管家"的企业财务分析与融资信号探测系统的高保真原型。这是一个内部使用的 B 端 SaaS 工具，面向财税服务公司的业务员使用。整体风格参考 Element Plus 组件库，中文界面，专业、简洁、数据密度适中。

### 产品背景

这是一家代账公司的内部工具。代账公司帮 95 家中小企业做记账报税，但利润很低。这个系统的核心价值是：从已有的财务数据中自动发现哪些企业可能需要银行贷款，生成财务健康分析报告，帮助业务员更早地对接融资服务（高利润业务）。

简单说：记账是入口，AI 分析是大脑，融资推荐是赚钱的地方。

### 需要设计的页面（共 6 个）

**页面 1：登录页**
- 简洁的登录表单：用户名 + 密码
- 产品名"智税管家"+ 副标题"企业财务健康分析与融资信号探测平台"
- 底部预留公司 Logo 和名称的占位区域（将来支持不同合作方品牌定制）

**页面 2：企业总览（首页/仪表盘）**
- 顶部统计卡片：企业总数（95）、本月已分析（12）、高融资潜力企业数（5）、待处理数据（3）
- 核心区域是企业列表表格，列包括：企业名称、行业、融资潜力评分（0-100 的进度条或数字）、最近分析日期、状态标签
- 评分 >= 70 的行用醒目的橙色/红色标签标记"高潜力"
- 表格上方有搜索框和筛选器（按行业、按评分区间、按状态筛选）
- 列表默认按融资潜力评分从高到低排序
- 每行有操作按钮：查看报告、导入数据
- 这个页面是业务员每天打开系统第一眼看到的，要能一眼看出"今天该跟进哪几家企业"

**页面 3：企业详情页**
- 顶部：企业基本信息卡片（企业名称、行业、注册资本区间、成立年份、负责业务员）
- 中部分两栏：
  - 左栏：融资潜力评分大数字展示（圆形仪表盘样式，0-100），下方显示"符合条件的银行产品"列表（2-3 个产品卡片，每个显示产品名称、额度范围、利率范围、基本条件）
  - 右栏：财务健康雷达图（五个维度：盈利能力、偿债能力、运营效率、成长性、现金流），每个维度 0-10 分
- 底部：历史分析记录时间线（日期 + 评分变化趋势）
- 右上角操作按钮：生成报告、导入新数据

**页面 4：数据导入页**
- 步骤条显示导入流程：选择文件 → AI 解析 → 人工确认 → 完成
- 第一步：文件上传区域（拖拽或点击上传），支持 Excel/CSV/PDF，显示支持的文件类型说明
- 第二步：AI 解析中的加载状态（进度条 + "AI 正在解析银行流水..."）
- 第三步（最关键）：AI 解析结果确认表格
  - 表格展示 AI 识别出的每一行数据（日期、摘要、收入、支出、余额）
  - 每个单元格可以直接编辑修改
  - 每行右侧有"确认"和"删除"按钮
  - 表格顶部有"全部确认"批量操作按钮
  - 用不同底色标记 AI 置信度（绿色=高置信、黄色=需确认、红色=可能有误）
- 第四步：导入完成，显示统计（共解析 XX 条，已确认 XX 条，已删除 XX 条）

**页面 5：财务健康报告页（在线预览）**
- 模拟一份完整的财务健康分析报告，这是给客户看的核心产出物
- 报告头部：报告标题"XX企业财务健康分析报告"、生成日期、报告编号，预留 Logo 占位区
- 报告正文包含：
  - 总体评级：用大字 + 颜色展示（如"B+ 良好"，绿色/黄色/红色对应不同等级）
  - 五维度分析详情：每个维度一个卡片，包含得分、关键指标数值、AI 生成的文字解读（2-3 句话，用中文，语气专业但易懂）、改善建议
  - 融资潜力评估区域：评分、匹配的银行产品建议、预估可贷额度范围
  - 风险提示区域：AI 发现的主要财务风险点（如"应收账款周转天数偏高，建议关注回款"）
- 右上角操作：导出 PDF、分享链接
- 整体排版要像一份正式的咨询报告，不是一个后台管理页面

**页面 6：新增企业表单**
- 简洁的表单页：企业名称、行业分类（下拉选择）、注册资本区间（下拉选择）、成立年份、负责业务员（下拉选择）
- 底部：保存 + 取消按钮
- 保存后跳转到数据导入页，引导用户上传第一份数据

### 设计要求

1. 整体风格：专业的 B 端工具，配色以蓝色系为主，搭配数据可视化的橙色/绿色/红色。参考 Element Plus 的设计语言
2. 左侧固定导航栏：包含首页（总览）、企业管理、数据导入、报告中心 四个菜单项
3. 所有页面顶部有面包屑导航
4. 使用真实感的中文示例数据填充（比如"南京XX机械有限公司"、"制造业"、评分 82 等），让看的人能直接理解这是干什么的
5. 报告页面要特别用心，因为这是给外部客户展示的核心交付物，体现专业度和 AI 分析的价值
6. 页面之间要有清晰的导航逻辑：总览 → 点击企业 → 企业详情 → 查看报告 / 导入数据
