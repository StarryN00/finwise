## 一、企业基础数据

**用途**：企业列表页、报告页下拉选择、Dashboard 统计

**数据来源**：前端界面手动创建，或通过 API 导入

| 字段 | 说明 | 测试建议 |
|------|------|---------|
| 企业名称 | 2-50 字 | 正常："上海智税科技有限公司"；边界：单字名、50字长名、含特殊符号 |
| 统一社会信用代码 | 18 位 | 正常：真实格式；异常：15位旧税号、重复税号 |
| 纳税人类型 | 一般纳税人 / 小规模纳税人 | 各准备 2-3 家，影响增值税计算逻辑 |
| 所属行业 | 制造业、科技、零售、服务业、建筑、金融、其他 | 每个行业至少 1 家，测试 Dashboard 行业分布图 |
| 注册资本区间 | 如 "100-500万" | 选填，用于融资评分参考 |
| 成立年份 | 如 2018 | 选填 |
| 省/市 | 如 "上海/上海市" | 选填 |
| 企业来源 | DIRECT / CHANNEL | 测试筛选功能 |
| 企业状态 | ACTIVE / SUSPENDED / CANCELLED | 各准备 2 家以上，测试 Dashboard 状态饼图 |

**建议总量**：8-12 家企业

**推荐配置**：
```
ACTIVE    × 6 家（覆盖 6 个行业）
SUSPENDED × 2 家
CANCELLED × 2 家
一般纳税人 × 6 家
小规模纳税人 × 4 家
```

## 二、发票数据（Excel 导入）

**用途**：发票管理页导入、匹配、税务报告计算

**文件格式**：.xlsx 或 .csv
**支持列名**（中文列名会自动映射，英文也行）：

| 列名（中文） | 列名（英文） | 类型 | 必填 | 示例 |
|-------------|-------------|------|------|------|
| 发票号码 | invoice_number | 文本 | 是 | "031002400211" |
| 发票类型 | invoice_type | 文本 | 是 | "销项" 或 "进项" |
| 开票日期 | issue_date | 日期 | 是 | "2026-04-15" |
| 金额 | amount | 数值 | 是 | 10000.00 |
| 税额 | tax_amount | 数值 | 是 | 1300.00 |
| 价税合计 | total_amount | 数值 | 是 | 11300.00 |
| 销售方名称 | seller_name | 文本 | 建议 | "上海某某供应商有限公司" |
| 销售方税号 | seller_tax_number | 文本 | 否 | "91310000XXXXXXXXXX" |
| 购买方名称 | buyer_name | 文本 | 否 | "上海智税科技有限公司" |
| 购买方税号 | buyer_tax_number | 文本 | 否 | "91310000YYYYYYYYYY" |

**建议数据量**：每家企业 20-50 张发票，其中销项:进项 ≈ 3:7

### 2.1 测试场景清单

| 场景 | 数据特征 | 目的 |
|------|---------|------|
| **正常发票** | 金额 1000~50000，日期集中在 2026-04 | 验证基础导入和列表显示 |
| **大金额发票** | 单张 > 100万 | 验证大数字格式化显示（¥1,000,000.00） |
| **零税额发票** | tax_amount = 0 | 验证免税/零税率场景 |
| **跨月发票** | 2026-03 和 2026-04 混合 | 验证按期间筛选和报告计算 |
| **作废发票** | 标记为作废 | 测试状态标签（pill--idle）显示 |
| **重复发票号** | 同一企业内发票号重复 | 测试导入去重或提示 |
| **缺失字段** | 缺少 seller_name 等选填项 | 测试容错 |
| **金额小数位** | 如 1234.567 | 测试金额精度处理 |

## 三、银行流水数据（Excel 导入）

**用途**：银行流水上传、AI 解析、发票-流水匹配

**文件格式**：.xlsx 或 .csv
**支持列名**（根据 imports.py 中的解析逻辑，常见银行流水格式）：

| 列名（中文） | 列名（英文） | 类型 | 必填 | 示例 |
|-------------|-------------|------|------|------|
| 交易日期 | transaction_date / date | 日期 | 是 | "2026-04-15" |
| 摘要 | summary / description / 交易说明 | 文本 | 是 | "货款-上海某某供应商" |
| 借方金额 | debit_amount / 支出金额 | 数值 | 是* | 11300.00 |
| 贷方金额 | credit_amount / 收入金额 | 数值 | 是* | 0.00 |
| 余额 | balance | 数值 | 否 | 125000.00 |
| 对方户名 | counterparty_name | 文本 | 否 | "上海某某供应商有限公司" |
| 对方账号 | counterparty_account | 文本 | 否 | "6222****8888" |

> *注：debit 和 credit 至少有一个有值

**建议数据量**：每家企业 30-80 笔流水

### 3.1 测试场景清单

| 场景 | 数据特征 | 目的 |
|------|---------|------|
| **精确匹配** | 流水金额 = 某张发票 total_amount，日期差 ≤ 3 天 | 测试第一层精确匹配 |
| **模糊匹配** | 流水金额 = 发票金额，日期差 4-7 天 | 测试第二层模糊匹配 |
| **多笔对一笔** | 多笔小额流水合计 = 一张大发票 | 测试多对一匹配场景 |
| **一笔对多笔** | 一笔大流水对应多张发票 | 测试一对多匹配场景 |
| **完全无匹配** | 流水金额与所有发票都不接近 | 测试未匹配统计 |
| **摘要含关键字** | 摘要包含 "货款"、"服务费"、"租金" 等 | 测试 AI 关键字匹配 |
| **负数/退款** | 贷方金额为负或借方为负 | 测试退款/冲正场景 |
| **节假日交易** | 周末/节假日日期 | 测试日期处理 |
| **超长摘要** | 摘要 > 100 字 | 测试显示截断 |
| **特殊字符** | 摘要含 emoji、全角符号 | 测试编码兼容性 |
| **余额递增** | 余额字段逐笔递增 | 验证余额列显示 |
| **大额转账** | 单笔 > 50万 | 验证大数字显示 |

## 七、快速生成模拟数据的脚本建议

如果不想手工准备，可以用 Python + pandas + faker 生成：

```python
import pandas as pd
import random
from faker import Faker
from datetime import datetime, timedelta

fake = Faker('zh_CN')

# 生成发票数据
def generate_invoices(count=30, enterprise_name="测试企业"):
    data = []
    for i in range(count):
        amount = round(random.uniform(1000, 80000), 2)
        tax = round(amount * 0.13, 2)
        total = round(amount + tax, 2)
        date = datetime(2026, 4, 1) + timedelta(days=random.randint(0, 30))
        inv_type = "销项" if random.random() < 0.3 else "进项"
        data.append({
            "发票号码": f"03100{random.randint(100000, 999999)}",
            "发票类型": inv_type,
            "开票日期": date.strftime("%Y-%m-%d"),
            "金额": amount,
            "税额": tax,
            "价税合计": total,
            "销售方名称": fake.company() if inv_type == "进项" else "",
        })
    return pd.DataFrame(data)

# 生成匹配的流水数据
def generate_bank_transactions(invoice_df, extra_count=20):
    data = []
    # 匹配部分：金额与发票一致
    for _, row in invoice_df.sample(min(15, len(invoice_df))).iterrows():
        date = datetime.strptime(row["开票日期"], "%Y-%m-%d") + timedelta(days=random.randint(-2, 3))
        data.append({
            "交易日期": date.strftime("%Y-%m-%d"),
            "摘要": f"货款-{row.get('销售方名称', '供应商')}",
            "借方金额": row["价税合计"],
            "贷方金额": 0,
            "余额": round(random.uniform(100000, 500000), 2),
        })
    # 未匹配部分
    for i in range(extra_count):
        data.append({
            "交易日期": (datetime(2026, 4, 1) + timedelta(days=random.randint(0, 30))).strftime("%Y-%m-%d"),
            "摘要": fake.sentence(),
            "借方金额": round(random.uniform(100, 5000), 2),
            "贷方金额": 0,
            "余额": round(random.uniform(100000, 500000), 2),
        })
    return pd.DataFrame(data)

# 使用示例
invoices = generate_invoices(30)
transactions = generate_bank_transactions(invoices, 20)
invoices.to_excel("test_invoices.xlsx", index=False)
transactions.to_excel("test_bank.xlsx", index=False)
```
