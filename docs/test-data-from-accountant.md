# FinWise 第一期 测试材料清单（代账公司视角）

> 用途：直接发给代账公司，告知他们需要提供哪些材料
> 核心原则：代账公司每月都在整理的资料，几乎无需额外加工

---

## 一、代账公司常见资料 → 系统需求映射

### 1. 公司基础信息表

**代账公司通常有**：企业开户时留存的营业执照、税务登记信息复印件、企业基础信息登记表

| 代账手头有的 | 系统需要的 | 说明 |
|-------------|------------|------|
| 公司名称 | 企业名称 | 完全一致 |
| 统一社会信用代码（税号） | 统一社会信用代码 | 完全一致 |
| 税务登记证上的纳税人类型 | 纳税人类型 | 完全一致 |
| 行业分类 | 所属行业 | 代账公司按国标行业分类填写 |
| 注册资本 | 注册资本区间 | 需要转换成区间（如 "100-500万"） |
| 成立日期 | 成立年份 | 完全一致 |
| 注册地址 | 省/市 | 提取省市即可 |

**需要代账补充的**：无。代账公司手头的企业档案完全够用。

### 2. 每月进项/销项发票明细

**代账公司通常有**：每月从税控盘或电子税务局导出的发票汇总表

**常见格式**：Excel，列名可能是：
- 发票代码、发票号码、发票编码
- 开票日期、日期
- 不含税金额、金额、合计金额
- 税额、税款
- 价税合计、总金额
- 销售方名称、销货方、卖方名称
- 购买方名称、购货方、买方名称

**系统支持自动识别的列名**（不用改）：
```
发票号码 / 发票代码 / 发票编码
发票类型 / 类型（进项/销项）
开票日期 / 日期
金额 / 不含税金额 / 合计金额
税额 / 税款
价税合计 / 总金额 / 税后合计
销售方名称 / 销货方 / 卖方名称
购买方名称 / 购货方 / 买方名称
```

**需要代账补充或说明的**：
| 问题 | 解决方案 |
|------|---------|
| 代账的表格里没有 "发票类型" 列（进项/销项） | 请代账分成两个文件给：《XX公司_2026年4月_进项发票.xlsx》《XX公司_2026年4月_销项发票.xlsx》，系统会自动识别 |
| 代账的表格里只有金额，没有分开的 "金额" 和 "税额" | 也可以用。系统会尝试计算（假设13%），但最好请他们提供分列的数据更准确 |
| 代账的发票明细只有 PDF 图片 | 请让他们导出电子表格（Excel/CSV），PDF 图片无法导入系统 |

### 3. 每月银行流水

**代账公司通常有**：每月从网银导出的对账单

**常见格式**：Excel，列名因银行而异，通常包含：
- 交易日期 / 日期 / 交易时间
- 摘要 / 交易说明 / 用途 / 摘要说明
- 借方金额 / 支出金额 / 借记金额 / 借货方金额
- 贷方金额 / 收入金额 / 贷记金额 / 贷货方金额
- 余额 / 账户余额
- 对方户名 / 对方户名 / 对手方名称

**系统支持自动识别的列名**（不用改）：
```
交易日期 / 日期 / 交易时间
摘要 / 交易说明 / 用途 / 摘要说明
借方金额 / 支出金额 / 借记金额
贷方金额 / 收入金额 / 贷记金额
余额 / 账户余额 / 当前余额
对方户名 / 对方户名 / 对手方名称 / 对方账户名
```

**需要代账补充或说明的**：
| 问题 | 解决方案 |
|------|---------|
| 流水里只有一列金额（不分借贷） | 可以用。系统会尝试根据正负号判断，但最好请他们提供含借贷列的流水单 |
| 每个银行一个文件 | 正常。每次导入时选择一家银行的文件即可 |
| 流水里有多家企业的交易混在一起 | 每个企业分开给，不要混在一个文件里 |

## 二、给代账公司的资料需求清单（可直接复制发微信）

```
亲，我们正在上线一个财务智能系统，需要准备一批测试数据。
能帮我导出以下材料吗？只要您手头现成的，不需要额外加工：

1️⃣ 企业基础信息表（您手头的登记档案就行）
   - 需要：公司名称、统一社会信用代码、纳税人类型、行业、注册资本、成立日期
   - 格式：Excel 或数据直接发我都行
   - 数量：提供 2-3 家客户即可

2️⃣ 发票明细（2026年4月的）
   - 进项发票一份（从税控盘或电子税务局导出的发票汇总表）
   - 销项发票一份
   - 格式：Excel 或 CSV，有发票号码、开票日期、金额、税额、销售方/购买方名称即可
   - 如果您的汇总表里进销项混在一起，请帮我分开两个文件
   - 数量：每家企业各 10-30 张发票即可

3️⃣ 银行对账单（2026年4月的）
   - 从网银导出的对账单（含交易日期、摘要、借贷方金额、余额即可）
   - 格式：Excel 或 CSV
   - 注意：每个企业单独一个文件，不要多家企业混在一起
   - 数量：每家企业各 20-40 笔交易即可

❌ 不需要的：凭证、合同、电子档案，我们不用这些
✅ 所有资料只是用于系统测试，绝对保密，不会泄露客户隐私

时间上有限制吗？大概什么时候能给到？
```

## 三、文件组织规范（建议这样命名，便于对应）

```
finwise_test_data/
├── enterprise_info.xlsx          # 企业基础信息表，2-3 家
├── 企业A_2026年4月_进项发票.xlsx
├── 企业A_2026年4月_销项发票.xlsx
├── 企业A_2026年4月_银行流水.xlsx
├── 企业B_2026年4月_进项发票.xlsx
├── 企业B_2026年4月_销项发票.xlsx
└── 企业B_2026年4月_银行流水.xlsx
```

**命名规则**：`{enterprise_name}_{YYYY}年{M}月_{data_type}.xlsx`

## 四、常见问题及应对

| 代账可能说的 | 应对方案 |
|-----------|---------|
| "发票汇总表里没有分金额和税额" | 请他们尝试从电子税务局导出详细版，或用通用模板填写。也可以先给我现有的格式，我看看系统能不能兼容。 |
| "只有 PDF 版发票，没有 Excel" | 请他们导出税控盘的汇总表（Excel 格式），而不是单张发票的 PDF。|
| "流水里没有余额" | 没关系，余额是选填字段，不会影响核心流程。系统会自动处理。 |
| "发票是按季度汇总的，不是按月" | 可以用。只要每张发票有开票日期，系统会自动按月份分类。 |
| "有些企业没有销项发票" | 正常。只给进项也行，系统支持缺少某一类型。 |
| "有些企业没有银行流水" | 没关系，但测试深度会受限（无法测匹配功能）。最好每家都有流水。 |
| "发票里有些是作废的" | 正好！请标注出来，或者不标注也行，系统有自己的作废判断逻辑。 |
| "能不能用模拟数据？" | 可以。如果他们有隐私顾虑，也可以用假名化的模拟数据。只要数据结构和格式一致即可。 |

## 五、最小可用集（如果代账只能给少量）

**如果代账很忙，最少需要**：

1. **1 家企业的基础信息**（手头就有）
2. **1 份进项发票明细**（至少 10 张发票，含金额、日期、发票号）
3. **1 份银行流水**（至少 20 笔交易，含日期、摘要、金额）

**共计**：3 个文件，代账 10 分钟内能找到。

---

## 六、代账给资料后的处理步骤

1. 你收到资料后，先用前端页面手动创建企业
2. 然后上传发票 Excel → 系统导入
3. 上传银行流水 Excel → 系统导入
4. 点击 "AI 解析" 流水
5. 点击 "发票匹配"
6. 生成各类报告
7. 对照报告数据和代账手工计算结果，验证准确性

**如果系统导入报错**：检查代账给的列名是不是与上面系统支持的列名差很远，可以手动改一下列名。
